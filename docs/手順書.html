1. はじめに（このシステムでできること）

このシステムは、マイクに話しかけると、AIが返事をして、合成音声でしゃべってくれる音声対話システムです。 Google Chrome（ブラウザ）を画面として使い、裏でPythonのプログラムが動きます。

  • 音声認識はChromeの機能（Web Speech API）を使うので、無料・登録不要。認識の途中経過もリアルタイムで画面に表示されます
  • 会話するAIは画面のプルダウンで切り替えられます：OpenAI (GPT) / Google Gemini / Anthropic Claude / 内蔵簡易AI
  • 内蔵簡易AIはAPIキーなしで動くので、キーの準備前でも動作確認ができます
  • AIの返事の声は VOICEVOX（ずんだもん等）か gTTS（Google翻訳の声・キー不要）を選べます
  • 「プロンプト」欄を書き換えると、AIの性格や話し方を自分で自由に変えられます（実習のメインテーマ！）
スクショ① システム起動後のメイン画面全体（左に設定パネル、右に会話エリアが見える状態。何往復か会話した状態が望ましい）
2024年版との違い（先生・TA向けメモ）
2024年版はPython製アプリ(PyQt5)＋Google Cloudの音声認識・音声合成でしたが、 2026年版はブラウザUI＋Web Speech APIになり、Google Cloudの契約・サービスアカウント・環境変数の設定がすべて不要になりました。 そのため2024年版手順書にあった「Google のAPIを使うための初期設定方法」「環境変数の登録」の章はこの手順書にはありません。

2. 準備するもの

もの説明
パソコンWindows または Mac。マイクとスピーカーが使えること

3. Pythonのインストール

すでにPython 3.10以上が入っている場合はこの章は飛ばしてOKです。ターミナル（Windowsは「コマンドプロンプト」）で確認できます：

python --version

Python 3.12.x のように表示されれば大丈夫です。

Windowsの場合

  1. https://www.python.org/downloads/ にアクセスし、「Download Python 3.x.x」ボタンをクリック
  2. ダウンロードしたインストーラーを実行
  3. 最初の画面で必ず「Add python.exe to PATH」にチェックを入れてから「Install Now」をクリック
スクショ② python.org のダウンロードページ（「Download Python」ボタンを赤矢印で指す）
スクショ③ Pythonインストーラーの最初の画面（「Add python.exe to PATH」のチェックボックスを赤矢印で指す）

Macの場合

最初からPythonが入っていることが多いですが、バージョンが古い場合は同じく python.org からインストールしてください。

5. 必要なライブラリのインストール

  1. ターミナル（Windowsはコマンドプロンプト）を開く
  2. 解凍したフォルダに移動する： 
    cd （解凍したフォルダの場所）/SummerTECH-CAMP-2026-voice-dialogue
    フォルダの場所がわからないときは、cd （cdのあとに半角スペース）とだけ打ってから、フォルダをターミナルの画面にドラッグ＆ドロップすると場所が自動入力されます。
  3. 次のコマンドでライブラリをインストールする： 
    pip install -r requirements.txt
スクショ⑥ ターミナルで pip install -r requirements.txt を実行し、インストールが完了した画面（「Successfully installed ...」の表示を赤枠で囲む）
pip が見つからないと言われたら、pip3 install -r requirements.txt や python -m pip install -r requirements.txt を試してください。

6. AIのAPIキーを取得する（使いたいAIだけでOK）

APIキーとは？：あなたのプログラムがAIのサービスを使うための「合鍵」となる文字列です。
まずはキーなしで試したい人へ：「内蔵簡易AI」はAPIキーなしで動きます。この章を飛ばして8章に進み、あとから必要になったら戻ってきてもOKです。
【重要】APIキーの注意事項
  • APIキーは絶対に他人に教えない・SNSやWebに書かないこと
  • キーは発行した直後にしか表示されないことが多いので、必ずコピーして自分だけのメモに保存すること
  • 利用量に応じて料金がかかるサービスがあります（実習では配布されたキーの指示に従ってください）

6.1 OpenAI（GPT）のAPIキー

  1. https://platform.openai.com/ にアクセスし、アカウントを作成（Sign up）またはログインする。Googleアカウントでも登録できます
  2. 登録にはSMSが受信できる携帯電話番号による認証が必要です
  3. ログイン後、画面左のメニュー（または右上の設定）から「API keys」を開く
  4. 「Create new secret key」をクリックし、名前（自由）を付けて作成
  5. 表示されたキー（sk-で始まる文字列）をコピーして保存する。この画面を閉じると二度と表示されません
スクショ⑦ OpenAI Platform（platform.openai.com）のログイン/サインアップ画面
※2024年版手順書のOpenAIの章のスクショは画面デザインが変わっている可能性が高いため撮り直し推奨
スクショ⑧ 「API keys」画面で「Create new secret key」ボタンを赤矢印で指す
スクショ⑨ 作成されたシークレットキーの表示画面（キー本体はモザイク・黒塗りにすること！「Copy」ボタンを赤矢印で指す）

6.2 Google Gemini のAPIキー

2024年版のような「Google Cloudの無料トライアル契約・プロジェクト作成・サービスアカウント」は一切不要です。Google AI Studioから数クリックで取得でき、無料枠があります。
  1. https://aistudio.google.com/ にGoogleアカウントでログインする
  2. 「Get API key」（APIキーを取得）をクリック
  3. 「APIキーを作成」をクリック
  4. 表示されたキー（AIzaで始まる文字列）をコピーして保存する
スクショ⑩ Google AI Studio のトップ画面（「Get API key」ボタンを赤矢印で指す）
スクショ⑪ APIキー作成後の画面（キー本体はモザイク・黒塗りにすること！コピーボタンを赤矢印で指す）

6.3 Anthropic Claude のAPIキー

  1. https://platform.claude.com/ にアクセスし、アカウントを作成またはログインする
  2. ダッシュボードの「API Keys」を開く
  3. 「Create Key」をクリックし、名前（自由）を付けて作成
  4. 表示されたキー（sk-ant-で始まる文字列）をコピーして保存する
スクショ⑫ Claude Console の API Keys 画面（「Create Key」ボタンを赤矢印で指す。既存キーが写る場合は名前・キーをモザイクに）

7. VOICEVOXのインストール（ずんだもんの声を使う場合）

AIの返事を「ずんだもん」などのキャラクターの声でしゃべらせたい場合は、無料の音声合成ソフトVOICEVOXをインストールします。

  1. https://voicevox.hiroshiba.jp/ にアクセスし、「ダウンロード」をクリック
  2. 自分のOS（Windows / Mac）用のインストーラーをダウンロードして実行（設問はすべて標準のままでOK）
  3. インストールしたらVOICEVOXアプリを起動しておく（起動しているだけで、本システムから声を借りられます）
スクショ⑬ VOICEVOX公式サイトのトップ（「ダウンロード」ボタンを赤矢印で指す）
VOICEVOXを使わない場合でも、キー不要の「gTTS（Google翻訳の声）」で読み上げできます（インターネット接続が必要）。

8. システムの起動

  1. ターミナルでプログラムのフォルダに移動する（5章と同じ）
  2. 次のコマンドでサーバーを起動する： 
    python server.py
  3. 下のような表示が出たら起動成功： 
    ==================================================
 SummerTECH-CAMP 2026 音声対話システム
 Chromeで http://localhost:5001 を開いてください
==================================================
  4. Google Chromeで http://localhost:5001 を開く
  5. マイクボタンを最初に押したとき、Chromeが「マイクの使用を許可しますか？」と聞いてくるので「許可する」をクリック
スクショ⑭ ターミナルで python server.py を実行し、起動メッセージが表示された画面
スクショ⑮ Chromeのマイク許可ダイアログ（「許可する」を赤矢印で指す）
終了するときは、ターミナルで Ctrl + C を押します。

9. APIキーの登録

GPT / Gemini / Claude を使う場合は、6章で取得したキーをシステムに登録します。方法は2つあります。

方法A：設定画面から登録（おすすめ）

  1. メイン画面の右上「⚙️ APIキー設定」をクリック
  2. 使いたいAIの欄にキーを貼り付けて「💾 保存する」をクリック
  3. 「✅ 設定済み」と表示されればOK。「← 会話画面にもどる」で戻る
スクショ⑯ APIキー設定画面（キーを入力した状態。キー本体は伏せ字表示のままでOK。「保存する」ボタンを赤矢印で指す）

方法B：ファイルに直接書く

フォルダ内の config.example.json をコピーして config.json という名前にし、中にキーを書き込んでも同じことができます（教員がまとめて設定するときに便利）。

10. 使い方

スクショ⑰ メイン画面に番号ラベル（①〜⑥）を書き込んだ図：
①使うAI/モデルのプルダウン ②プロンプト入力欄 ③声の設定 ④会話エリア ⑤音声認識の途中結果表示（黄色い帯） ⑥マイクボタンとテキスト入力欄

基本の流れ

  1. 左パネルの「使うAI」で会話したいAIを選ぶ（まずは「内蔵簡易AI」で動作確認がおすすめ）
  2. 「🎤 マイクON」ボタンを押して話しかける
    • 話している途中の認識結果が黄色い帯にリアルタイム表示されます
    • 発話が確定すると会話エリアに表示され、AIが返事をします
  3. AIの返事が合成音声で再生されます（再生中は音声認識が自動で一時停止し、終わると再開します）
  4. マイクを使わずに、下のテキスト入力欄から送信することもできます

プロンプトでAIの性格を変えてみよう（実習のメイン！）

「📝 プロンプト」欄の文章を書き換えると、AIの話し方や性格が変わります。書き換えた内容は次の発話から反映されます。

プロンプトの例期待される変化
あなたは関西弁で話すお笑い好きのAIです。返事は50文字以内。関西弁でボケてくれる
あなたは語尾に「なのだ」を付けて話すずんだもんです。ずんだもん口調になる（VOICEVOXの声と合わせると◎）
あなたは英語の先生です。日本語の発話に対して簡単な英語で返事し、日本語訳も付けてください。英会話の練習相手になる
スクショ⑱ プロンプトを書き換えて（例：ずんだもん口調）、実際に口調が変わった会話のスクリーンショット

声を変えてみよう

  • 「🔊 声の設定」で VOICEVOX（要：VOICEVOXアプリ起動）と gTTS を切り替えられます
  • VOICEVOXでは話者（ずんだもん、四国めたん等）も選べます

会話のリセット

AIは過去の会話を覚えています。話題を切り替えたいときや、プロンプトを大きく変えたときは「🗑️ 会話をリセット」を押しましょう。

11. うまく動かないとき（トラブルシューティング）

症状対処法
マイクボタンを押しても反応しないブラウザがChromeか確認。アドレスバー左のアイコンからマイクを「許可」にする
「このブラウザは音声認識に対応していません」と出るGoogle Chromeを使ってください
「VOICEVOXエンジンに接続できません」と出るVOICEVOXアプリを起動してから、もう一度話しかける。使わない場合は声の設定を「gTTS」に変更
「APIキーが設定されていません」と出る9章の手順でキーを登録する。または「内蔵簡易AI」に切り替える
AIの返事がエラーになる（401など）キーの貼り付けミス（前後の空白・改行）がないか確認。キーの利用枠が残っているか各サービスの管理画面で確認
python server.py でエラーになる5章の pip install -r requirements.txt が成功しているか確認。python3 server.py も試す
ポート5001が使用中と出るすでに起動している別のサーバーを Ctrl+C で終了してから再実行
自分の声にAIの声が混ざって誤認識されるイヤホンを使う（スピーカーの音をマイクが拾うのを防げます）
